25 - New Selectors

Modern CSS selectors like :is(), :where(), :has(), and more.

  • :is() — group selectors with forgiving matching
  • :where() — like :is() but zero specificity
  • :has() — parent selector based on children
  • :focus-visible — focus only on keyboard interaction
  • ::selection — style selected text
  • :target — target the current URL fragment
