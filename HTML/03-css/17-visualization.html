block ocupa todo el ancho · inline se ajusta al contenido · none oculta y elimina espacio · flex/grid layouts modernos.

visibility: visible | hidden

visible
hidden
El elemento hidden ocupa espacio pero no se ve (diferencia con display:none).

overflow: visible | hidden | scroll | auto

visible
Contenido que se desborda y se ve fuera del contenedor.
hidden
El desbordamiento se recorta, no se ve lo que sale.
scroll
Barras siempre visibles (horizontal y vertical).
auto
Barras solo cuando hay desbordamiento.

z-index: control de apilamiento

z:1
z:2
z:3
z:0
Mayor z-index = mas arriba. Solo funciona en elementos posicionados (relative, absolute, fixed, sticky).
