34 - CSS Variables

Custom properties (--var) store reusable values, making themes and maintenance easier.

Variables definidas en :root

--purple-primary: #a050ff;
--purple-dark: #4a1a7a;
--purple-light: #c090ff;
--radius-md: 14px;
--shadow-default: 0 4px 12px rgba(160,80,255,0.2);

Reutilizando variables

background: var(--purple-primary) etc.

Variables en botones

background: var(--purple-primary) y var(--purple-dark)

Ventaja: cambio global

Si cambias --purple-primary en :root, se actualiza en TODOS lados. Ideal para temas.
