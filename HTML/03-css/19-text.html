19 - Text Properties

CSS offers many properties to style and format text content.

  • text-align
  • text-decoration
  • text-transform
  • text-indent
  • letter-spacing
  • line-height
  • word-spacing
  • white-space
  • text-shadow

text-align

Alineado a la izquierda (por defecto)
Centrado horizontalmente
Alineado a la derecha
Texto justificado: Este parrafo se estira para que ambas margenes queden alineadas, creando un bloque uniforme como en periodicos impresos.

text-decoration

Subrayado con underline
Tachado con line-through
Linea superior con overline
Sin decoracion (none) - tipico para links

text-indent

La primera linea de este parrafo tiene una sangria de 2em. El resto del texto fluye normalmente, ideal para articulos y documentos formales.
